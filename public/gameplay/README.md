# Captures de gameplay personnelles

Déposez ici vos propres captures (JPEG/PNG/WebP, 1280 px de large conseillé, < 300 Ko), puis associez-les à une fiche du Radar dans `collector/overrides.json` :

```json
{ "items": { "r-48606a2278": { "capture": { "src": "gameplay/perroquet-three-sheets.webp", "credit": "ViceScopeIV", "alt": "Panneau de ventilation derrière Three Sheets Liquor" } } } }
```

Seules vos captures (droits détenus) vont ici : aucune image d'article ou de vidéo tierce n'est copiée dans le dépôt. Les miniatures YouTube restent servies par YouTube.
