# V0.21 — Data Engine, branche de revue

Base publiée V0.20.2, commit `7eed616`. Le Data Engine reconstruit les cinq projections locales, vérifie leur intégrité au build et conserve le dernier import accepté lors d’une collecte GTABase incomplète. La version livrée ajoute une durée de vie de sept jours pour les pages sans date de modification et écarte la relation de variante visant un article.

Le rapport détaille les changements par bundle, les effectifs, le cache, les mesures avant/après et la couverture de validation. [Rapport Data Engine](DATA-ENGINE.md)
